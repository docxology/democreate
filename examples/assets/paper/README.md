# Optional curated-paper assets

Committed `lambda_sweep.png`, `architecture.png` and `pages/` are historical
illustrations, not a complete reproducible paper-input bundle. Original media
identity is unrecorded. Required external paper figures/PDF/source must be
provided explicitly to `examples/make_paper_showcase.py --paper-root ...`.
The builder stages them here beside the Demo JSON without writing the source
project; no unrelated paper is substituted when an input is missing.
