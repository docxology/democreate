# assets/

Example images are Demo-relative inputs, not automatically captured activity.
[`make_assets.py`](../make_assets.py) creates `architecture.png` and optionally
captures `dashboard.png` with a usable browser; absent-browser runs preserve the
retained image. [`make_showcase.py`](../make_showcase.py) stages
`graphical_abstract.png`, `themes.png` and `paper_fig.png` from manuscript figures.
The curated `paper/` subtree contains separately sourced figures/page renders;
generic regeneration is not a new paper extraction or provenance proof.
