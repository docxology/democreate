# Standalone integration declarations and native task authority

DemoCreate has no `humos.*` runtime import dependency. This sidecar describes
possible lab relationships; it is not evidence that a registry, dashboard scanner
or shared task service is connected. Native runtime/dependencies and gates remain
owned by `pyproject.toml`, the project guides and root `AGENTS.md`.

## Read declarations without inferring live integration

| File | Declared responsibility | Not established by this file |
|---|---|---|
| `sidecar.toml` | Schema-1 identity `democreate`, standalone coupling and registry options | Successful registration, resolved external registry or host-setup permission |
| `bridges.toml` | `feeds` relationship with `hum-dashboard`; `informs` relationship with `hum-docxology` | A working shared-output scan, active clone-manager connection or checkout layout |
| `conformance.toml` | Runtime/gate aliases and coverage threshold | Passing checks or permission to import another project's lane commands |

`auto_register = true` and the configured relative registry anchor are
declarations, not successful registration receipts. Dashboard consumption of MP4,
timed HTML image previews, transcripts and unsigned provenance artifacts remains
unverified here. The old manager checkout spelling is not a current path contract.
Do not infer bidirectional synchronization or introduce an adapter from these
descriptions.

## Preserve the repository's existing task formats

[`tasks.yaml`](../tasks.yaml) is the native task/Gantt history with its existing
`demo_create` project key, task IDs, status vocabulary and dated notes.
[`TODO.md`](../TODO.md) is the native agent-facing backlog using Markdown
checkboxes. Session Workflowz todos are execution aids, not automatically
persisted taskboard updates. No live taskboard or shared-schema synchronization
is verified by these files.

Keep those distinct authorities and the sidecar's `democreate` identity intact;
do not silently rename IDs, change formats or invent interoperability mappings.
These declarations do not authorize external writes or replace native admission,
custody and verification requirements.
